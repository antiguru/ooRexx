# Phase 7 — streams and platform, implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to
> implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the stream model, `.File`, the standard streams and monitors, commands and
`ADDRESS`, the platform layer, external routine resolution and the `Sys*` subset, so that a Rexx
program on this crate can read and write files, issue commands, call another program, and so that
the ooTest suite can start.

**Architecture:** The interpreter grows two pieces of state it never had -- a shadow environment and
a shadow current directory -- and one new object shape: a stream's native state riding in
`Body::Instance`'s `native` slot. Everything else is filling in entry points that already exist:
the 24 `file_*` and 24 `stream_*` rows of the `LIBRARY REXX` registry, the eight excluded stream
builtins, the ten `.local` names, and the last arm of the call resolver.

**Tech Stack:** Rust; `rexx-exec` (`dispatch/native.rs`, `run.rs`, `lib.rs`, `input.rs`,
`invocation.rs`, `require.rs`, `environment.rs`, `trace.rs`), `rexx-core` (`body.rs`), `rexx-lib`
(the embedded `StreamClasses.orx`), plus two new dependencies (`rustix`, `filetime`).

**Spec:** `docs/superpowers/specs/2026-09-11-phase-7-streams-platform.md`

**The surveys are part of the spec.** Six measured reports live in
`.superpowers/sdd/2026-09-11-phase-7/survey/` (`A-streams.md`, `B-file.md`, `C-monitors.md`,
`D-commands-env.md`, `E-external-resolution.md`, `F-rexxutil.md`) and are copied to
`docs/superpowers/records/2026-09-12-phase-7/` at the close. Each task below cites the section of
the survey that holds the measured oracle transcripts it must reproduce. **A task's brief carries
those citations rather than a re-transcription of the bytes**: the report is the measurement, and
restating a measured transcript in a brief is how it gets corrupted.

## Global Constraints

* **No `unsafe`.** The workspace lint is `deny`; a per-site exception is Moritz's alone to grant and
  has not been granted for this phase. Where a syscall is needed, use the safe wrapper the spec
  names (`rustix`) or a `/proc` read.
* **No process-global state is mutated** (spec A2): no `std::env::set_var` / `remove_var`, no
  `std::env::set_current_dir`, and no write to file descriptor 0, 1 or 2 from interpreter code. The
  shadow environment and shadow directory are the only ones Phase 7 code reads after `run_program`
  starts. Task 2 lands the test that asserts the crate's sources name none of those functions.
* **No new dependency** beyond the two the spec names.
* **Correctness is byte-identical stdout, stderr and exit status against the C++ oracle**, read on
  **three separate descriptors, never `2>&1`**. Oracle runs use the standard wrapper
  `( ulimit -v 1048576; LD_LIBRARY_PATH=/home/moritz/dev/repos/ooRexx/build/lib /home/moritz/dev/repos/ooRexx/build/bin/rexx FILE )`
  from a fresh empty directory.
* **Probe hazards.** Read `rust/corpus/oracle-crashes.txt` before an unusual probe and never run its
  entries -- entries 10, 11 and 12 are this phase's own. Never
  `select; when 1 = 0 then; when 2 = 2 then nop; end`. Never `NUMERIC DIGITS` above 1000. Never
  `.Package~new` on a file inside the repository. A symbol `x` or `b` directly followed by a quote
  is a hex or binary literal. Put `timeout` on both sides of any probe that loops or reads input.
* **File-system and command probes and witnesses stay inside their own directory.** Commands are
  limited to `echo`, `printf`, `true`, `false`, `sh -c 'exit N'`, `cat`, `ls`, `pwd`, `env`.
* **Four gates, all green at the closing commit:** `cargo fmt --all --check`;
  `cargo clippy -j 4 --workspace --all-targets -- -D warnings`;
  `cargo test -j 4 --release --workspace --no-fail-fast -- --test-threads=8`;
  `REXX_CORPUS_GATE=1 cargo test -j 4 --workspace --no-fail-fast -- --test-threads=8`. Record each
  exit status unpiped and the count of `ok` result lines. **Commit before a long gate run and leave
  the tree frozen until it finishes.** Wait on a running gate in ~1-hour stretches, not 10-minute
  polls.
* **Comments are minimal** (`rust/CLAUDE.md`, Moritz 2026-08-27): a one-sentence overview,
  parameters/returns/panics, and properties the implementation does not show. No narrative, no
  history, no counts of in-repo sets. Measurements and reasoning go in the spec, the survey or a
  record.
* **Every extent claim is derived and its command committed.** No "all", "none", "every" or a count
  in prose without the enumeration that produced it.
* **Write each negative control's prediction before running it**, and mark each part confirmed,
  falsified, or unobservable.
* **A method that exists and does nothing is not implemented.** Build the body or leave the name
  refusing loudly; never a shell that answers nothing.
* **A refusal names the phase that owes the work**: `Phase 8` for native libraries, `Phase 10` for
  RXAPI, the external queues and the RexxUtil remainder. After this phase, no refusal names
  `Phase 7`.
* Never `git add -A`; stage explicit paths. Never amend; never force-push; never
  `git reset --hard`; never `git checkout -- <path>` on an edited file; never bare `git stash` /
  `git stash pop`. Commit messages are written to a file and passed with `-F`.
* Scratch files live in the session scratchpad, never in the repository.
