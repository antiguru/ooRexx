# Phase 6.1: loose ends of closed phases, implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to
> implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move activation-scoped state off `Activity`, give every loud refusal that names Phase 5 or no
phase a disposition (implement most), report parse errors as SYNTAX, fix interactive-debug pauses and
input, and add a deterministic simulation mode with a seeded gate judged by the crate's own
invariants.

**Architecture:** Task 1 moves the clock, RANDOM seed, SETLOCAL list, propagated condition, SELECT
CASE value and debug-pause flag onto `Activation` inside its 512 bytes. Tasks 2 to 6 implement the
refusal groups scout A dispositioned and the debug and parse-error defects scout B measured, each
witnessed against the oracle. Task 7 lands the disposition test and `closed_phases` with Phase 5.
Tasks 8 to 11 build `SwitchMode::Sim`: seeded streams, a clock seam, an inline pool, policies
(random bounded preemption, uniform, opt-in PCT), scheduler invariants, a decision trace with replay,
then the seeded gate and the mutant judgements. Task 12 closes.

**Tech Stack:** Rust; `rexx-core`, `rexx-exec`, `rexx-parse`. No new dependency.

**Spec:** `docs/superpowers/specs/2026-10-07-phase-6-1-loose-ends.md` at `04b5f0ff8` (rulings R1-R8 in
its section 6). Evidence it cites: `.superpowers/sdd/2026-10-07-phase-6-1/scout-{a,b,c,d}-report.md`
(probe texts in their appendices; scout A's probes and harness under
`/tmp/claude-1000/p61/sa/`, scout B's under `/tmp/claude-1000/p61/sb/probes/`, which may be gone: the
appendices are authoritative), `scout-d-prototype.patch`, the spec reviews beside them, and the

## Review Focus

1. **State a REPLY continuation carries.** Every field Task 1 moves must still travel with a
   continuation (the `Activation` box moves; nothing is copied). Task 1 keeps the P89 witness, rewritten
   to the oracle's rule, and adds a REPLY probe per moved field.
2. **Internal calls deep in recursion.** RANDOM and SETLOCAL walk to the nearest top-level activation;
   a deep internal recursion must not change their answers or turn the call path O(depth). Task 1 adds a
   witness that draws RANDOM and SETLOCALs at internal-call depth 2000 and matches the oracle.
3. **A loop with no COUNTER pays nothing.** Task 2 keeps COUNTER off the step op of loops without one;
   its perf check runs `emptyloop`, `decloop` and `rexxcps`.
4. **The simulation mode must be invisible when off.** Every default-mode run is byte-identical and
   no per-clause branch is added. Task 8's corpus run in default mode and Task 9's perf check pin it.
5. **A seed must replay.** Two runs of one seed in separate processes give the same decision-trace
   hash and outcome. Task 9's determinism test and Task 10's self-test pin it, including a program that
   sleeps, reads `time('e')`, starts activities and calls a native routine.
