## Where to start

**Measure before you design.** Run each option against the oracle and against this crate from a
fresh empty directory, three descriptors separately, both engines, and build the table of what
actually differs. The row set names the options; it does not tell you which of them this crate
already handles, which refuse loudly, and which answer wrongly. **The last category is the one that
matters** -- a silent wrong answer is this phase's worst defect class, and the phase has already
produced one (`>x`, fixed in `989c307e2`).

**A directive is installed by running Rexx code.** This project has twice assumed otherwise and been
wrong. Whatever `::OPTIONS` does, it does at install time, so probes that look identical as source
can differ in when they take effect. Check the ordering rather than assuming it.
