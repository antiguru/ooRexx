### Important (F3): evaluate-and-discard is not the whole rule, and the divergence is stdout, not trace

`select case 2 / when 2 then / when 3 then nop / otherwise say 'O' / end / say 'after'` (p7, no trace anywhere): the oracle prints **`O` then `after`**; we print only `after`.
The oracle acts on a false absorbed `WhenCase`'s result by branching to its `false_target` (the `OTHERWISE`); our arm discards the result unconditionally.
The trace probe (p5b) shows the same thing from the other side: after the absorbed comparison pair (`>>> "3"`, `>>> "0"`), the oracle echoes `otherwise`, `nop`, `end`, which we never run.
A **true** absorbed `WhenCase` does not run its consequence on either side (p9, match), so the divergence is confined to the false path's branch.
This means the fix round's disclosed `WhenCase` narrowness ("cannot reproduce the `>>>` pair") is honest but **understated**: the gap is behavioural, visible without trace, and therefore needs either a follow-up fix or an exclusions row that says stdout, not formatting.
The plain-`WHEN` false-absorbed analogue is deliberately **unprobed**: that shape is SF #2018's neighbourhood, and the coordinator's standing instruction is not to probe around it. Our arm treats true and false alike (`Flow::Next`); whether the oracle branches there too is unknown and should be settled, if at all, by someone deciding to risk one oracle call, not by me under a rule not to.

### Important (F4): comma-list conditions trace nothing, listed or absorbed

`trace r / select / when 1, 1 then say 'hit' / otherwise nop / end` (p8, a *listed* `WHEN`, nothing absorbed): the oracle emits one `>>>` per list element (`>>> "1"`, `>>> "1"`) and no combined line; we emit no `>>>` at all for a comma-list condition.
The absorbed comma-list probe (p3) diverges identically.
This is not a fix-round regression; it is a trace-commit gap the fix round's probing perimeter reached but did not cross, and it presumably applies to every comma-list condition site (`IF`/`WHEN`/`WHILE`/`UNTIL`).
Trace-only, rc and stdout match.
