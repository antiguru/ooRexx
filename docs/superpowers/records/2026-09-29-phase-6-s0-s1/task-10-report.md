## Plain DO

`flat_loop_start` answers a new `FlatStart::Block` for an **unlabelled** `LoopKind::Simple`:
`flat_block_start` runs the block's own clause (`in_clause`, `settle_block_indent(true)`), as
`run_loop_with_header`'s `Simple` arm does, and the `Op::LoopRun` arm ends its region into the body.
Nothing is pushed. The `END` is the existing `Op::Exec` region, whose `exec_flow` arm is already
`Flow::Next`. That region provides the echo, the boundary and the indent. An unlabelled block
passes every escaping `Flow` through unchanged (`do_body_outcome` with `is_loop: false` and no
label), so it needs no frame.

**A labelled block (`DO LABEL l`) still falls back**, because a `LEAVE l` needs a frame to absorb it.
This is the one remaining Rexx-reachable `NestedLoop` pin besides the refused forms. The pinning
probe for `NestedLoop` now uses `do label l`.

## Seam

`src/scheduler.rs`:

- `ExecOutcome { Done(Flow), Park(ParkReason), Split(Flow) }`. `Split` carries the flow the current
  activity goes on with.
- `ParkReason { Guard }`. `Park`, `Split` and `Guard` carry `cfg_attr(not(test), expect(dead_code))`,
  because only the test-only arm constructs them.
- `pub(crate) trait Scheduler` declares only what the driver calls (P20). That is `spawn() -> bool`,
  which is `false` in `SingleActivity` because no second activity exists to take a continuation.
- Left out, each landing with its first caller: `run_until_park`, `park`, `unpark`,
  `yield_at_slice`, `exit_for_native`, `exit_for_block`, `post_completion`, `request_baton` and
  `stop_the_world`. `run_until_park` and `park` were removed in fix round 1 with the driver's park
  path (P21). No `expect(dead_code)` or `allow` is on any seam method.
- `SingleActivity` is a field of `Interp`, used through static dispatch.

Driver:

- `exec_instruction` returns `Result<ExecOutcome, Failure>`. GUARD and REPLY answer through
  `exec_guard`/`exec_reply`, which return `Done`. Every other instruction goes through `exec_flow`,
  which is the former body.
- The `Op::Exec` arm handles `Done` inline. Every other outcome goes to the cold, out-of-line
  `exec_suspends`.
- **Park is loud in S1** (`op_not_driven("an activity park")`), ruling P21. The driver's Park path
  lands with S2's first real parker. Every working park path measured in fix round 1 moved
  per-clause codegen by more than +1.0% on some program (the table is under `## Task 10` in
  `phase-6-perf.md`).
- **Split** calls `spawn()`. With `false`, the continuation stays with this activity and the carried
  flow is the region's answer. With `true`, it is loud.
- Test-only arm: a `#[cfg(test)]` thread-local script (`scheduler::script`/`take_scripted`), read
  first thing in `exec_instruction` and off during the library bootstrap. Tests in
  `ir/drive/tests.rs`:
  - `a_parked_exec_is_loud`: a scripted Park at `drop z` is loud in a driven region and inside
    `do label l` (nested). Only `before` prints, and each program runs clean unscripted.
  - `a_split_exec_goes_on_with_its_flow`: `interpret 'signal l'` answering Split lands at `l`, and the
    split counter reads 1.
