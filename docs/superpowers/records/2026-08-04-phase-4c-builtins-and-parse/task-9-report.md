## Things inferred rather than measured, flagged

* **A `::routine` does not inherit the environment.** Read from the C++
  (`RexxActivation`'s routine constructor sets `currentAddress` from the instance
  default rather than from the parent), not measured -- this crate never enters a
  `::routine` body, so no code path depends on it. Recorded in
  `Activation::address`' doc comment as what the C++ does.

  separate `platform/windows/MiscSystem.cpp::validateAddressName`; not read in

  value is per platform and quotes the unix one, which is measured.
* **`environment` and `dynamic` are never both `Some`.** Taken from the grammar,
  not measured. The code orders `environment` first to mirror the C++, and says
  in a comment that the order decides nothing today.
