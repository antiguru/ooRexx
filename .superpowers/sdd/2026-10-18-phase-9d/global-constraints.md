## Global Constraints

* **Specialization is internal** (`rust/CLAUDE.md`). No refusal of the form "this crate does not
  keep X", and no side map keyed by a numeric id. `tests/representation_refusals.rs` stays green
  with `ALLOWED` unchanged.
* **Behaviour.** The corpus differential stays identical except where a task names the programs it
  changes. Each changed program is witnessed against the oracle.
  * New witnesses go in `rust/corpus/phase-9.txt`.
  * A new `corpus/lang/*.rex` needs its `crates/rexx-parse/tests/sourceline_oracle/<name>.txt`,
    generated by that test's oracle driver.
  * A witness comparing collection output compares it as a multiset (Deviation 33: hash order is
    unspecified).
* **`unsafe`**: no new site (`crates/rexx-core/tests/unsafe_sites.rs`).
* **Oracle runs**: `( ulimit -v 1048576; LD_LIBRARY_PATH=/home/moritz/dev/repos/ooRexx/build/lib
  timeout -k 5 20 /home/moritz/dev/repos/ooRexx/build/bin/rexx FILE )` from a fresh empty
  directory you `mkdir`. Compare stdout, stderr and status separately. Read
  `rust/corpus/oracle-crashes.txt` first.
* **Memory caps**: every crate interpreter run under `memcap 2G` and `timeout`. Every test binary
  and build under `memcap 8G`, `-j 4`, `CARGO_INCREMENTAL=0`, and an agent's own `CARGO_TARGET_DIR`
  under the session scratchpad.
* **Read-only**: the C++ tree, `samples/`, `build/`, `ootest/`, `oodocs/`, `testbinaries/`, `api/`.
* **Prose**: comments and docs state decisions, never a mechanism that does not exist yet, and
  never a set's size.
  * No em-dashes.
  * A false sentence is deleted.
  * Extent claims carry the command that derived them.
  * Read every witness's stdout to confirm each path it claims actually prints.
* **Shell**: no `bash -c` or `sh -c` wrappers. `rm` only with literal absolute paths, no globs.
  * Never `git checkout`, `stash` or `reset`.
  * Reverse a mutant by an exact edit and confirm with `git diff --stat`.
  * Never `git push`.
* **Foreground checks**: every check runs in the foreground with a bound under 10 minutes.
* **Per-task check, at most 10 minutes in all:**
  * `cargo fmt --all --check` from `rust/`;
  * `cargo clippy -p <touched crates> --all-targets -- -D warnings`;
  * the test binaries covering what changed;
  * the refusal tables, `owners`, `closed_phases`, `phase_ten_reasons` and `representation_refusals`;
  * the gated release corpus (`REXX_CORPUS_GATE=1 ... --test corpus`);
  * the whole ooTest suite through the harness from `rust/` (4m38s at the 9c close):
    `REXX_SUITE_GATE=1 REXX_SUITE_TABLE=<durable path>/table.tsv CARGO_INCREMENTAL=0 memcap 8G
    cargo test -j 4 --release -p rexx-exec --test suite l3_core_suite`. The task reports every
    test whose result differs from the previous task's table, and from
    `docs/superpowers/records/2026-10-15-phase-9c/close/suite/tests.tsv` for the first. While the
    phase runs, the command's exit 101 is expected. The changed rows are the result.

  Record each command and its exit status in the report, unpiped.
* **Per-task perf check.** A task that changes the interpreter's run path (any `src/` file outside
  `builtin/` argument checking and refusal text) runs `bench-programs/callgrind.sh -B 0.5
  -p "startup interpret parse churn sayloop" pin=/home/moritz/dev/repos/ooRexx-p9-pin/rexx-run
  head=<the task's binary> -o /home/moritz/dev/repos/ooRexx-p9-pin/cg-9d/<task>` from the repo's
  `rust/`. The task's own delta is its figure against the pin minus the previous perf-checked
  task's figure against the pin, as the ledger records it. The first baseline is the first block
  of `docs/superpowers/records/2026-10-15-phase-9c/close/callgrind.txt`, at `48fb59b51`, the only
  block holding all five programs. The
  delta is at most +0.05% whole process on each program, and the figure against the pin stays
  under +0.5%. The task copies its table into its records directory. New error and refusal construction stays `#[cold]` and out of line.
  This run is the one exception to the 5-minute bound.
* **Serial instances.** Task instances run one at a time. They share
  `refusal-dispositions.tsv`, `refusal-sites.tsv`, `phase-9.txt`, `suite-9d-set.txt` and
  `phase-4-exclusions.txt`.
* **Refusal tables**: deleting or relabelling a `Loud` site re-derives
  `rust/corpus/refusal-sites.tsv` (`REXX_REFUSAL_SITES_REFRESH=1 cargo test -p rexx-exec --test
  refusal_sites`) in the same commit.
* **Records**: outputs a record cites go in `docs/superpowers/records/2026-10-18-phase-9d/`, never

* **Fix rounds**: three per cluster or finding. The remainder then goes to the controller, who
  takes it to Moritz with a proposed owner or Deviation.
* **Shared paths**: an item that needs a change outside its task's files is reported. The
  controller moves it, and it is not widened inside the task.

   (conditions, tracebacks, streams). Expect every test passing at the 9c close to still pass.
   Every task runs the whole suite and reports the rows that changed, and Task 10's join
   against the 9c close's per-test record catches the rest.

   refusal text, and Task 4 runs the yaml group once with the repository's copy too.

   are not UTF-8. Expect the oracle's answer for a name with a `'80'x` byte. The streams cluster's
   instance adds one.

   REPLY and propagated paths. Expect each to print the oracle's lines. The cluster's instance
   witnesses one program per path.

   per class and method. Expect a pair reached only through `enhanced` or a subclass instance to be
   found. Task 3 probes each pair through a plain instance, a subclass instance and an
   `enhanced` instance.
