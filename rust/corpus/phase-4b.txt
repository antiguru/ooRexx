# Phase 4b corpus subset -- the union with phase-4a.txt is what the harnesses
# read, not this file alone. Every entry in phase-4a.txt stays in force.
#
# One path per line, relative to this directory (rust/corpus/). Lines starting
# with # are comments; blank lines are ignored. Same format as phase-4a.txt,
# and read by the same `read_subset`, which unions the two in first-seen order
# and drops a repeat.
#
# WHY THIS FILE EXISTS AND WHY IT IS NOT AN EXTENSION OF phase-4a.txt.
# phase-4a.txt's own header excludes INTERPRET by definition ("no CALL/RETURN/
# PROCEDURE/USE/SIGNAL/RAISE/INTERPRET"), so a witness for a construct 4b
# implements cannot go there without making that header false. Criterion 1
# (tests/coverage.rs) requires every in-scope variant to be witnessed by some
# program in the subset it reads, so the moment a variant moves into scope its
# witness has to land in a file that admits it -- this one.
#
# WHAT THIS SUBSET ADMITS, one line per construct as it lands. Everything
# phase-4a.txt admits, plus:
#
#   INTERPRET (4b Task 1) -- a fragment whose text is built at run time, a
#   fragment inside a DO body, and a name bound inside one fragment and read
#   back from a later one, which is the case that reaches Activation::extra.
#
#   CALL and RETURN (4b Task 3) -- CALL to an internal label (the plain and
#   the CALL (expr) forms), RETURN with and without a value, the shared
#   variable pool a callee with no PROCEDURE gets, and RESULT. NOT the other
#   two CALL arms as of that task: CALL ON/OFF was Task 7's (and is now
#   listed below) and CALL ns:name is Phase 5's and still fails loudly.
#
#   PROCEDURE, PROCEDURE EXPOSE, USE ARG/USE STRICT ARG and the >name
#   variable-reference argument (4b Task 5) -- an isolated callee pool, an
#   exposed name aliased back into the pool it came from, exposure chased
#   through two levels, the plural indirect EXPOSE (list) form, a whole stem
#   exposed, positional and omitted and defaulted USE ARG targets, and
#   USE ARG >name aliasing the caller's own variable. NOT USE LOCAL, which
#   rexx-parse rejects at parse time in every position but one and which has
#   no legal use here at all (this crate has no method invocations), and NOT
#   PROCEDURE EXPOSE of a single compound tail (`expose a.1`), which fails
#   loudly -- see Loud::compound_expose.
#
#   ExprKind::Call, the internal-function expression form (4b Task 4) -- f(...)
#   resolved against the calling activation's own labels and evaluated for its
#   value, reusing the same nested-activation machinery CALL uses. NOT
#   CallTarget::Literal ("f"(...)), which never searches the label table and
#   still fails loudly naming 4c, symmetric with CALL "SUB".
#
#   SIGNAL label and SIGNAL VALUE (4b Task 6) -- SIGNAL unwinding a DO
#   unconditionally (no search, no name to match, unlike LEAVE), landing on
#   a label past it, and SIGNAL VALUE tracing its own >K> line before
#   searching the label table with the rendered text.
#
#   SIGNAL ON/OFF, CALL ON/OFF, RAISE and NOVALUE (4b Task 7) -- a trap
#   firing on an ordinary raise and on an uninitialised read, SIGL set to the
#   raising clause, a trap disabled once it fires and re-armed, RAISE SYNTAX
#   with an ARRAY substitution list, RAISE USER with a RETURN value whose
#   CALL ON handler runs at the next clause boundary, and SIGNAL OFF leaving
#   the last raise untrapped. NOT RAISE ... ADDITIONAL (a, b): the
#   parenthesised list is ExprKind::List, which is Phase 5's and still fails
#   loudly -- RAISE ... ARRAY (a, b) reaches the identical oracle bytes.
#
#   PUSH and QUEUE (4b Task 8, I15) -- an expression evaluated to string form
#   and traced exactly like SAY, and a bare PUSH/QUEUE tracing a null string.
#   The one thing no program in this subset can witness is the queue's own
#   storage or interleaved order, since nothing that reads it back (PULL,
#   PARSE PULL, QUEUED()) exists before 4c -- see lang/push_queue.rex's own
#   header and queue.rs's unit tests, which is where that order is pinned.
#
# The INTERPRET row's third clause is stated carefully because it was wrong
# twice (it was "the third clause" until the CALL row landed between them; a
# positional reference to a list that grows goes stale by construction). It
# requires
# BOTH the write and the read to be inside fragments: a bare `say zork` in this
# file's enclosing body would put ZORK in that body's own plan, `slot_of` would
# find it there, and the extra path would never be reached. Measured by
# instrumenting slot_of's growth branch -- `interpret "zork = 42"` followed by
# `say zork` gives zero hits, followed by `interpret "say zork"` gives one.
# Anyone editing lang/interpret_dynamic.rex should re-run that check rather
# than assume the property survived, because it is invisible in the output:
# both spellings print 42 and both match the oracle.
#
# WHAT IT STILL EXCLUDES. Everything phase-4a.txt excludes except INTERPRET,
# CALL (including CALL ON/OFF), RETURN, PROCEDURE, USE ARG, SIGNAL (all three
# forms), RAISE, PUSH and QUEUE, which is to say: no builtin function calls --
# condition() included, which is why no program here reads a trapped
# condition's name -- no PARSE/ARG/PULL, no message sends, no :: directives,
# no command clauses, no DO WITH, and no DO OVER on a stem. The
# authoritative, machine-checked list is tests/owners.rs's INSTRUCTION_TAGS/
# EXPR_TAGS: anything still carrying an `Owner::Phase` there fails loudly and
# cannot appear in any program listed in this file. Later 4b tasks move their
# own construct across that line and delete its name from the paragraph above
# in the same change.
#
# **That rule is per *arm* where a variant is split, and CALL is the one case
# left.** owners.rs's table is variant-grained, so `InstructionKind::Call`
# reads `Owner::Phase("Phase 5")` -- for `Call::Qualified` (`CALL ns:name`)
# alone, since Task 3 implemented `Call::Named`/`Call::Dynamic` and Task 7
# implemented `Call::Trap`. A program using any of those three belongs here.
# `InstructionKind::Signal` is `Owner::InScope` outright since Task 7, all
# three of its arms being implemented. loud.rs's `expand_for_witnesses` is
# where the arm-level truth is machine-checked; reading the coarse `Call` tag
# alone would say that no program here may contain a `CALL` at all, which is
# not what the table means.
#
# A program listed here must also obey the corpus's one standing rule
# (README.md, "The one rule: determinism"): same bytes on every run, on every
# machine, with no clock, no PID, no filesystem and no locale in its output.

# New for 4b Task 1 -- INTERPRET:
lang/interpret_dynamic.rex

# New for 4b Task 2 -- the error report's echo stack. interpret_dynamic.rex
# above raises nothing and traces nothing, which was deliberate: through Task 1
# a fragment's own clause was never echoed, so any program that traced or
# raised inside fragment text diverged by one line per fragment clause. This
# one raises on purpose, and its whole value is the two-line echo the report
# now prints. Its own header says which wrong answer each field would produce.
lang/interpret_error_echo.rex

# New for 4b Task 3 -- CALL and RETURN, under trace r throughout. Review
# finding I1 (Task 4 fix round 1) found the indent claim this entry used to
# make was never true of this program's own differential run against the
# oracle: corpus.rs's DEVIATION 0 collapses the run of spaces D2r's indent
# rule produces, so `call inner` (inside a DO inside `outer:`) echoing at 6
# where a "2 x depth" rule would say 2 is pinned by run.rs's own unit tests
# (a_callees_clauses_echo_at_the_calling_clauses_indent_plus_two), which
# compare raw bytes outside DEVIATION 0's reach, not by this program. What
# this program's differential run does pin: the clause sequence and line
# numbers on stderr, NUMERIC DIGITS inherited by a callee and not written
# back, and RESULT settled on return. The variables are not decoration
# either -- a witness with none in it passes against an implementation that
# wrongly gives every callee its own pool.
lang/call_return.rex

# New for 4b Task 4 -- ExprKind::Call, the internal-function expression form,
# under trace r for the same reason call_return.rex is. Also review finding
# I1: the D2r indent this entry used to claim as pinned here is likewise
# collapsed by DEVIATION 0 and is pinned by run.rs's own unit tests instead
# (current_value_indent_is_restored_after_a_nested_expression_call and its
# neighbours), not by this program. What this program's differential run
# does pin: stdout byte for byte -- RESULT set before the call and read back
# unchanged after it, unlike CALL, which settles RESULT on return -- and
# stderr's clause sequence and line numbers.
lang/call_expression.rex

# New for 4b Task 5 -- PROCEDURE and PROCEDURE EXPOSE. Its header states, per
# block, which wrong answer each would print; the values are chosen so that
# none of them equals its own variable's derived name, which is what makes an
# exposure failure and a non-exposure failure print differently. The
# transitivity block is the one that cannot be got right by accident: it needs
# both a name chased two levels up and a name that stops one level up, from a
# single PROCEDURE.
lang/call_procedure_expose.rex

# New for 4b Task 5 -- USE ARG, USE STRICT ARG and the >name argument. The
# `dropped` block deliberately uses a routine with no PROCEDURE, because a
# target that USE ARG drops is only observable from outside the routine when
# the pool is shared.
lang/use_arg_forms.rex

# New for 4b Task 6 -- SIGNAL to a label and SIGNAL VALUE, under trace r
# throughout. Its own header states why SIGNAL fires on the loop's first
# pass rather than its second -- originally a KNOWN GAP in a Controlled
# DO/LOOP's own retrace, closed at Task 9 and re-measured there, so the
# first-pass form is now a choice rather than a requirement -- and why the
# final unresolved SIGNAL comes last (a raise ends the program).
lang/signal_forms.rex

# New for 4b Task 7 -- condition traps, RAISE and NOVALUE, under trace r
# throughout. Its own header states, per block, which wrong answer each would
# print, and why it contains no `exit <value>`: that clause's `>>>` line was
# a gap in this crate's EXIT arm, unrelated to conditions, so a program with
# one in it would have diverged for the wrong reason. Closed at Task 9, whose
# witness is tests/trace_oracle/exit_value.rex. The witness value
# is a single accumulated string rather than a per-block flag, so a block that
# silently did not run removes its own segment from the output instead of
# leaving it unchanged -- and no segment equals any variable's derived name,
# which is what stops an unset flag reading as data.
lang/condition_traps.rex

# New for 4b Task 8 -- PUSH and QUEUE, under trace r throughout. Its own
# header states what it can and cannot pin: nothing here can differentially
# witness the queue's own storage or interleaved order, since nothing that
# reads it back (PULL, PARSE PULL, QUEUED()) exists before 4c, so without
# TRACE R this program would pass against any implementation including one
# that discards every line. What TRACE R adds is real: each PUSH/QUEUE's own
# >>> line, matching SAY's own evaluate-render-trace path, plus a bare
# PUSH/QUEUE tracing a null string rather than being skipped. The
# interleaved order itself is pinned by queue.rs's own unit tests instead.
lang/push_queue.rex

# New for 4b Task 9 -- RAISE SYNTAX ... ARRAY's substitution list and its own
# trace lines. It runs under trace i because >A> is an intermediates-level
# prefix and nothing shows it under trace r; that is a property of the prefix
# and of this program, not a census of the others. (The sentence here used to
# add "the one program in this subset that is, which is what every other 4b
# program uses"; enumerating the subset showed the second half already false
# -- four of the others set no trace at all.) Its raise is deliberately
# untrapped, because
# the thing it pins -- an omitted array element holding its place in the
# substitution list rather than closing up -- is observable only in the error
# report, condition('o') being 4c's. Its own header states which wrong answer
# a gap-closing implementation prints.
lang/raise_array_substitution.rex

# New for 4b Task 9, review round 1 (F2) -- a Controlled loop's re-test blamed
# on the clause that transferred control back to it. Reachable only because
# the control variable is genuinely re-read: the body leaves it non-numeric
# and the BY addition on the next re-test raises 41.1. Untrapped, because the
# blame line is only observable in the report. Its first loop is the adjacent
# passing case (an ordinary loop that must still run to completion), and its
# ITERATE is two blocks deep so that "the ITERATE's own indent" and "the loop
# body's indent" are different numbers.
lang/loop_retest_blame.rex
