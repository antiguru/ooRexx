# Phase 8 corpus subset -- the C ABI boundary. The union with the earlier
# phase-*.txt files is what the harnesses read, not this file alone.
#
# One path per line, relative to this directory (rust/corpus/). Lines starting
# with # are comments; blank lines are ignored.
#
# A program here may load one of the oracle's compiled extensions, from the
# directory its .env sidecar names: {oraclelib}, the oracle checkout's
# build/lib, the same bytes on both sides. (The in-crate tests open this
# worktree's build/lib copy, a second build from identical sources.) It does
# not rebuild one, and it prints no address: a .Pointer renders differently on
# every run.

# Task 8: the directives that name a library, and what each load failure
# reports. The three EXTERNAL forms and ::REQUIRES LIBRARY all resolve the
# name through one path, so the same library named twice is loaded once.
lang/library_requires_missing.rex
lang/library_method_entry_missing.rex
lang/library_routine_entry_missing.rex
lang/library_attribute_entry_missing.rex

# Task 8: a ::METHOD bound to a procedure of librxregexp.so, run end to end --
# CSELF across sends, SetObjectVariable into the method's own scope, and the
# one StringData address RegExp_Pos's pointer arithmetic depends on.
lang/library_method_external.rex

# Task 8: ::REQUIRES LIBRARY, Package~loadLibrary and the loadExternal class
# methods, which answer rather than raise for a name that is not there.
lang/library_loads_once.rex

# Task 8: what the boundary refuses before the extension's own code runs, and
# what it raises after that code has returned.
lang/library_method_missing_argument.rex
lang/library_method_extra_arguments.rex
lang/library_method_raises.rex

# Task 9: the native UNINIT at finalization. RegExp_Uninit writes to no
# descriptor, so each of these reads its DropObjectVariable back through a
# written method in the scope the extension stores CSELF into: the driven
# sweep, the termination sweep, and a second finalization reaching the
# extension's own null-CSELF guard.
lang/library_uninit_collected.rex
lang/library_uninit_termination.rex
lang/library_uninit_twice.rex

# Task 10: which file a native method's failure is reported against. A raise
# the boundary makes for itself names the package the EXTERNAL directive was
# written in; one the extension raises for itself propagates to the caller.
lang/library_method_package_blame.rex
lang/library_method_program_blame.rex
lang/external_method_package_blame.rex

# Final-review fixes: a string parameter's conversion is REQUEST('STRING')
# alone, a raise inside the argument's MAKESTRING is that raise, and an
# argument with no string value names the declaring package with no line.
lang/library_string_argument.rex
lang/library_method_no_string_value.rex

# Final-review fixes: a library load failure in a required package names that
# package's own file and line.
lang/library_required_method_library_missing.rex
lang/library_required_method_entry_missing.rex
lang/library_required_routine_entry_missing.rex
lang/library_required_attribute_entry_missing.rex

# Final-review fixes: what ~package answers for a library-backed EXTERNAL and
# for a loadExternal* answer, which shares the library's code object.
lang/library_method_package.rex

# Final-review fixes: a library name that loaded nothing is asked again.
lang/library_load_retried.rex

# Final-review fixes: the library search is the LD_LIBRARY_PATH the
# interpreter started with, whatever the program writes into it afterwards.
lang/library_search_path_fixed.rex

# Residual fixes: a library routine is one object per routine table entry,
# whichever spelling asks for it and however many directives bind it.
lang/library_routine_package.rex

# Residual fixes: a directive binds a library procedure while its package is
# translated, so a later directive's refusal does not undo it.
lang/library_bound_before_refusal.rex

# Residual fixes: a package whose translation raised is translated again when
# it is asked for again, and one that translated and failed to install is not.
lang/library_package_retried.rex

# Residual fixes: a Method or Routine object passed as a context hands its
# package on, and a loadExternal* answer nothing has bound still answers.
lang/library_context_package.rex

# Residual fixes: a package whose translation raised keeps its settings and none
# of what it declared, though a library method it bound still names it.
lang/library_package_discarded.rex

# Surface Task 1: .environment and .local answer every Directory method, the
# whole-collection reads in the oracle's order, and .local's entries present
# from the first clause.
lang/environment_directory_surface.rex
lang/local_directory_surface.rex

# Surface Task 1: a string-keyed collection takes each index as a string
# argument, so an index with no string value is 88.909.
lang/directory_index_string_value.rex

# Surface Task 1 fix round: .local's STDQUE taken out by setEntry with no value
# and by setMethod, neither of which reads the queue it held.
lang/local_stdque_removal.rex
