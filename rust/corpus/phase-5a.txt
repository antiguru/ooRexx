# Phase 5a corpus subset -- the union with phase-4a.txt, phase-4b.txt and
# phase-4c.txt is what the harnesses read, not this file alone. Every entry
# in those three stays in force.
#
# One path per line, relative to this directory (rust/corpus/). Lines starting
# with # are comments; blank lines are ignored. Same format as the earlier
# phase files, and read by the same `read_subset`, which unions the files in
# first-seen order and drops a repeat.
#
# Task 1 built the harness plumbing this file needs (an unnormalised stderr
# comparison mode, a directive walker admitting `::CLASS`/`::METHOD` without
# panicking, and this file wired into every harness that reads a phase subset
# list) and added no corpus program of its own. Each later task appends its
# own witness here as its own construct starts agreeing with the oracle.

# Task 4: the directives that install. `::CLASS`, `::METHOD` and `::ATTRIBUTE`
# installing under it, and `::CONSTANT`'s two shapes -- a well-formed
# parenthesised expression (evaluated and discarded, since nothing can read
# it back before message dispatch exists) and the two ways it fails: the
# expression itself raising, and the structural "no preceding ::CLASS" check.
lang/directive_class_installs.rex
lang/directive_method_installs.rex
lang/directive_attribute_installs.rex
lang/directive_constant_expression_installs.rex
lang/directive_constant_expression_fails.rex
lang/directive_constant_expression_needs_class.rex
lang/directive_constant_expression_blames_the_last_class.rex

# Task 6 fix round 1 (ruling R12): what an operator, a condition and a builtin
# do with one of these objects as an operand -- the half the two
# implementations agree on. The half they do not is loud, which a corpus file
# cannot witness, and `eval.rs`'s `object_operand_tests` carries instead.
lang/environment_object_operands.rex

# Task 6 fix round 2: the DO header's numeric positions convert their value
# through a unary operator, so R12 reaches them too. This is the boundary
# either side of the three it refuses -- FOR, a bare repeat count, NUMERIC
# DIGITS and a builtin argument all read the value's text instead and go on
# agreeing.
lang/environment_object_in_a_loop_header.rex

# Task 6 fix round 4: RAISE substitutes its additional information, and the
# oracle array-converts it only under a SYNTAX condition. This is the side
# that does not convert, and every line of it was refused by the first
# version of that fix.
lang/environment_object_in_a_raise.rex

# Task 7: invoking a Rexx method body. A class method is the one kind a
# program can reach in this phase -- every other receiver whose behaviour

# accessor is written in Rexx, and the `>I>`/`<I<` pair a method activation
# adds around the callee's own clause echoes. The last two are compared raw
# (see corpus.rs's RAW_STDERR_COMPARISON), because the indents are the point.
