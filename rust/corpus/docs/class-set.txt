# Table C's class row set: every <section id="cls..."> across
# fundclasses.xml, collclasses.xml, utilityclasses.xml and
# streamclasses.xml.
#
# One `name<TAB>entry<TAB>section<TAB>book:line<TAB>status<TAB>reason
# <TAB>construction<TAB>directives<TAB>method-owner`
# per line, in book order then document order.
#
# Three departures from the sections, each named rather than mechanical.
# RegularExpression is out of the set: it is delivered by `::requires
# "rxregexp.cls"` and that file is not on this build's search path, measured
# 43.901 rc 213. RexxInfo is an `instance` row rather than a `class` row:
# its .environment entry is an instance, not the class object. ArgUtil is
# added: it is an .environment class the books document nowhere, and its
# only citation is the XML comment at provide.xml:838.
#
# `status` is the spec's three row statuses. `covered` is a class a bare
# ~new constructs, or one opted in with a committed construction
# program. `not-covered` says no construction program is committed and
# CARRIES NO CLAIM ABOUT THE ORACLE. `unreachable` is grounded in a
# sentence of the reference itself and belongs to the classes whose
# sentence says instances come only from native code; each such
# sentence is re-read at the line it cites on every run.
#
# `construction` is the Rexx expression a method row's instance arm binds
# `o` to, and it is what `covered` claims: every `covered` row carries one
# and every other row carries `-`. A class whose bare ~new constructs
# carries that bare ~new; one opted in by CONSTRUCTION_PROGRAMS carries the
# book's own syntax for obtaining an instance. gate_table_c.rs derives the
# instance-arm probe from this field, so a `covered` status and the program
# the probe runs cannot say different things.
#
# `directives` is the directive the probe carries below its readbacks, for a
# `covered` row whose expression reads what a directive defines; every other
# row carries `-`.
#
# `method-owner` is the phase that owes this class's method rows an `agree`,
# which gate_table_c.rs reads instead of one constant over every method row.
# `5c` is the default; the classes waiting on the stream and timer entry
# points carry the phase the native registry files those under, and
# `deferred-rexxcontext-stackframes` is not a phase and names the work its
# rows wait on. A row that can never agree is derived from `status` and the
# arm rather than named here.
#
# Derived by `cargo run -p rexx-extract --bin rexx-extract-docs`, whose
# module is `src/docs/classes.rs`. Re-derived and compared in both
# directions by `tests/extract_docs.rs`.
#
