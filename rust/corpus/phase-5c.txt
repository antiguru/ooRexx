# with # are comments; blank lines are ignored. Same format as the earlier
# phase files, and read by the same `read_subset`, which unions the files in
# first-seen order and drops a repeat.

# still landing this file could not exist: gate_table_c.rs's

# could not pay that until their owner became a property of the row's class.
# So 5c's witnesses waited in test binaries instead, and this file is where
# they land.
