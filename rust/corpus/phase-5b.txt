# Phase 5b corpus subset -- the union with phase-4a.txt, phase-4b.txt,
# phase-4c.txt and phase-5a.txt is what the harnesses read, not this file
# alone. Every entry in those four stays in force.
#
# One path per line, relative to this directory (rust/corpus/). Lines starting
# with # are comments; blank lines are ignored. Same format as the earlier
# phase files, and read by the same `read_subset`, which unions the files in
# first-seen order and drops a repeat.
#
# Task 0 wired this file into every harness that reads a phase subset list
# (SUBSET_FILES in corpus.rs, coverage.rs, collect_stress.rs and ir_dual.rs;
# the unguarded literal in trace_oracle.rs; and EXPECTED_SUBSET_5B beside
# EXPECTED_SUBSET_5A in coverage.rs) and added no corpus program of its own.
# Each 5b task appends its own witness here as its own construct starts
# agreeing with the oracle, and updates EXPECTED_SUBSET_5B in the same commit.

# Task 5: `UNINIT`. `obdes.rex` is the gate row a class-side `UNINIT` makes
# agree. `uninit_instance_collected.rex` is the delivery driven by a
# collection and `uninit_instance_retained.rex` the one D69 owes: a
# class-scope variable roots the instance for ever, so no collection can ever
# reach it and only the termination sweep runs its finalizer.
# `uninit_class_inherited.rex` and `uninit_class_mixin.rex` are the two arms
# `obdes.rex` cannot see, where the class that fires declares no `UNINIT` of
# its own -- one reaching it through `SUBCLASS` and one through `INHERIT`.
# `uninit_class_inherit_runtime.rex` is the `INHERIT` arm again as a runtime
# send, which is a second registration path and also the only row whose
# entries are not all made at directive-install time.
# `uninit_class_sweep_order.rex` pins the sweep's order over class objects
# against declaration order, which it contradicts on every class.
# The rows below those are each a delivery *point* rather than an order:
# `uninit_class_uninherit.rex` is a registration that outlives its method and
# runs nothing, `uninit_allocating_finalizer.rex` is a finalizer that
# allocates, which bounds the termination sweep, and
# `uninit_nested_collection.rex` and `uninit_nested_collection_at_exit.rex`
# are a collection driven from inside a finalizer, which must run no
# finalizer of its own. Those two reach different copies of the interlock:
# the first drives its outer finalizer from a program-level `GC('force')`,
# the second is reached because the program ends, and it is the only row that
# reaches the termination sweep's copy. Both print only whether the inner
# finalizer ran inline, never when it did run: the oracle answers that two
# ways across runs.

# Task 7: `~copy`, `~run`, `~send`/`~sendWith` and `~start`/`~startWith`.
# `object_copy.rex` writes through the copy and reads the receiver back,
# which is what tells a copied pool from a shared one, and its
# finalizers are forced one at a time because the order two pending ones run
# in is not reproducible. `object_run.rex` is the allowing arm, which the
# refusal a program context meets never reaches: it carries the option table,
# the source shapes, and D67's own reading -- the body's EXPOSE finds the
# object's FLOAT pool and never the class's. `object_send.rex` carries the
# array form of the message name, whose second item is the class the search
# starts from, against a subclass that overrides the base's method, and
# `object_start.rex` reads every message's `~result` before its `~completed`
# and `~hasError`, which is all D68 leaves assertable.
# The refusal rows beneath them are what a witness of the answers cannot see.
# `object_run_refusals.rex` pins run's step order -- the option is read before
# the restricted check, so an unrelated class's method meets 93.915 first --
# and `object_send_refusals.rex` pins the message-name shapes, including that
# the count checked is the array's last filled slot rather than its size and
# that `sendWith` decodes the name before reading the array where `startWith`
# does the opposite. The two untrapped rows carry the substitutions a trapped
# one cannot: `Class~copy`'s own refusal, which is where a class object stops
# short of `Object~copy`, and the name-shape refusal beside the same send
# spelled with a string.
