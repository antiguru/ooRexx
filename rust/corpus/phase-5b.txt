# Task 1: `~new`, `INIT`, and the instance seam. The concept-row probes this
# task makes agree, and the witnesses of what those rows do not send.
# `instance_naming.rex` sends `~string`, `~defaultName`, `~objectName`,
# `~objectName=`, `~class` and `~isA` to an instance, which no gate-table row
# does -- `creo.rex` sends `~type`/`~balance`/`~rate` and `abscla.rex` sends to

# them sends rather than stored text, and `instance_naming_raises.rex` is that
# claim's stderr arm: a `defaultName` that raises reports `Compiled method`
# frames for `OBJECTNAME` and `STRING` that no stored rendering could make.
# `instance_self_reassigned.rex` is a method body assigning over `SELF` and
# then allocating, the shape the receiver's rooting turns on.

# Task 1 fix round: the positions a named instance IS the value of. `~objectName=`
# can give an instance a name that spells a number or a truth value, and the
# oracle converts it in every position below and refuses it as an operator's
# left operand, where this crate's own refusal is loud and no differential row
# can carry it. Nothing else in the corpus puts an instance in an operand
# position at all, which is how a build answering `o + 1` shipped.
lang/instance_named_operands.rex
