/* A guarded native method nested inside a guarded Rexx method that turns
   its own lock off with SetGuardOff gives back only its own level: the
   outer method keeps the lock, so another activity's guarded method waits
   for it to end. The started send first makes the lock table count. */

  m = self~start('other')
  call SysSleep 0.2
  say 'outer done'
  return m
::method other

  say 'other ran, x =' x
